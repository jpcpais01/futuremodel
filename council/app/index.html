    How to read this

    This is a forward paper record. Every decision is written to a hash-chained ledger with its timestamp before the market sees it, and it fills at the next regular-session open with a 0.1% trading cost. Values use total-return prices, the same as the benchmarks.

    There is deliberately no backtest. A language model already knows what happened in the past, so any backtest of the council would be contaminated by hindsight. Only the record built from here forward counts, and a few weeks of it is noise. Judge it after several months.

    Settings

    Anthropic API key

    Read from the ANTHROPIC_API_KEY environment variable only. It is never written to disk by this app.

    Open PowerShell and run this once, with your own key, then restart the app:

    setx ANTHROPIC_API_KEY "sk-ant-..."

    Create or rotate keys at console.anthropic.com.

    Default budget

    Used for scheduled and emergency sessions.

    Weekly session

    The council reviews and rotates the portfolio once a week. Trades fill at the next open.

    Catch up if missed

    If the computer was off at the slot, run within three days.

    Daily watch

    Weekdays after the close, one cheap call checks every holding against its own sell condition.

    Emergency sessions

    Convene automatically when the watch says a thesis has broken. Off means it only notifies you.

    Keep running in the tray

    Closing the window keeps the schedule alive.

    Phone link

    Lets the Oazy Council phone app follow the chamber and the portfolio over your home Wi-Fi. Only devices on your local network with the pairing code can connect.

    Pairing

    In the phone app, enter one of these addresses and the code.

    Phone can convene

    Allow the phone to start sessions and the watch. Real sessions cost money.

    SEC contact

    The SEC asks automated clients to identify themselves with a name and email. Optional; stays on this computer.
